# Development and Reproduction

## Setup

```bash
npm install
npm run dev
```

Ordinary browser development requires no secrets or environment variables. Native export is outside the judging build; its public routes and package commands are intentionally absent. The lockfile pins the Faust runtime. Generated browser factories are committed for reproducibility and regenerated by every production build.

## Commands

```bash
npm run faust:compile   # compile canonical .dsp sources and refresh manifest/license
npm test                # domain, state, agent, analysis, real Faust renders, and build gates
npm run test:native     # native generation, artifact, parity, and safety contracts
npx tsc --noEmit        # TypeScript contracts
npm run lint            # source quality
npm run build:web       # portable Sites/Vinext build from committed Faust artifacts
npm run build           # pinned Faust regeneration plus production build
```

## TDD extension workflow

1. Add a failing catalog/domain test for the new contract.
2. Add failing real Faust offline-render tests at the required sample rates.
3. Edit the canonical `.dsp` source and run `npm run faust:compile`.
4. Update the checked source fingerprint in the catalog only after reviewing the generated metadata.
5. Integrate the persistent live processor without rebuilding the source for parameter changes.
6. Add validation, WebMCP, persistence, and UI regression coverage before publishing.

Do not add a browser-only DSP approximation. Do not silently migrate or delete unsupported legacy data. Do not clamp invalid external edits. Do not describe a frozen browser recipe as a compiled or validated VST3.

## Source and licensing

The Faust source written for this project is MIT-licensed. `@grame/faustwasm` 0.16.6 declares LGPL-3.0 in its package metadata and ships an LGPL-2.1-or-later `COPYING.txt`; the exact upstream text is deployed at `public/faust/FAUSTWASM-LICENSE.txt` and must remain with redistributed runtime artifacts. Phaser and Flanger use the Julius O. Smith section of `phaflangers.lib`; the 3-Band EQ uses the STK-4.3-declared shelf and peak functions in `filters.lib`. Compressor Clean uses `co.compressor_stereo`, and Glue uses the MIT-style `an.rms_envelope_tau` envelope with `co.compression_gain_mono` rather than the GPLv3 RMS compressor family. Limiter uses project-authored gain and ceiling logic with `an.amp_follower_ar` and bounded delay primitives rather than the GPLv3 `co.limiter_lad_*` family. Tremolo uses project-authored oscillator, shaping, comparison, and dry/wet logic. Auto Wah uses the pinned `an.amp_follower_ar`, `fi.resonlp`, and `fi.resonhp` functions. Stutter uses project-authored control and capture logic around Faust's `rwtable` primitive rather than copied third-party effect code. Release licensing must still be reviewed against the pinned upstream files.

## Native export boundary

Native source retains the controlled Mac-worker contracts for compilation, VST3 packaging/signing, Steinberg validation, state restoration, and browser/native comparisons at 44.1/48/96 kHz. The judging build does not expose HTTP routes or package commands for that system. Selected-DAW discovery, automation, reopening, and audible/render behavior remain separate manual proof.
